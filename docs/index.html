Do you trust your seed entropy?

MEGA is an experimental offline Android app for people who want to see where a BIP39 mnemonic comes from. You roll the dice, enter the results, and review the math that turns physical entropy into 24 words.

The Educational Problem

Many wallets generate seeds correctly, but the user often cannot inspect the entropy source. A weak, biased, broken, or malicious random generator can make a seed weaker than it appears. MEGA does not ask users to trust hidden randomness for the seed path; it asks them to create entropy physically and verify the conversion.

Entropy is the root

A mnemonic protects funds only if the starting randomness is strong enough.

Dice are visible

A fair d6 roll is a physical event the user can perform and record offline.

Software becomes a calculator

The app converts rolls to BIP39 words and exposes intermediate values for review.

How MEGA Thinks About Trust

Trust lessDo not rely on device randomness, network state, clocks, identifiers, or hidden app state for the mnemonic entropy.
Verify moreCheck the dice count, base-6 value, rejection decision, entropy bytes, checksum, 11-bit groups, hex indexes, and word-list lookup.

Why GrapheneOS Helps

MEGA can run on stock Android, including an internet-connected device, because the app itself is offline. For serious testing, an offline GrapheneOS profile gives reviewers stronger device-level controls around that claim.

Beta Status

Experimental, not independently audited. Do not use MEGA beta output to secure meaningful funds. Test with disposable roll sequences and report issues without sharing real seed words, PINs, passphrases, or private dice history.
